1. Visualizing Training and Sampling

1.1 Constructing noisy training inputs

I constructed a noisy training input by interpolating between a clean image and Gaussian noise. At t=0, the image is pure noise; at t=1 we have the clean image. interpolate(image, ε, 0) == ε and interpolate(image, ε, 1) == image.

def interpolate(image, noise, t):
    return (1 - t) * noise + t * image

As t increases, the kitten becomes more visible.

1.2 Classical denoising

If we gaussian blur the noisy image, it is possible to cancel independent, zero-mean noise. While blurring can reduce noise, it also removes the high-frequency components of the image, such as details and fine lines.

1.3 One-step denoising

Now, instead of just blurring the image, I use a pretrained flow model to denoise. Given a noisy image at time t, we can use the predict_velocity(x,t,condition) function to predict the velocity at that given point, and extrapolate to get the clean image in one prediction. 

def one_step_denoise(x, t, condition, predict_velocity):
    return x + (1 - t) * predict_velocity(x, t, condition)

As t gets closer to 1, the denoised image approaches the clean image with more details. However, at a small t like 0.25, the estimated clean endpoint is missing details like the kitten's ears.

1.4 Visualizing velocity

To visualize what changes the model is adding and what exact change is required to recover the original image, we visualize the predicted update and ground-truth update and an error heatmap. For the error heatmap, I computed the root-mean-square (RMS) difference between the two updates across RGB at each pixel.

1.5 Iterative denoising with Euler sampling

Since the learned one-step velocity is not the same as each velocity along the timeline, the one-step denoising process is not fully accurate. We can iteratively denoise the noisy image using euler sampling and predict a new velocity every step. 

@torch.inference_mode()
def euler_sample(x_start, t_start, step_size, velocity):
  states = [(t_start, x_start)]

  while t_start < 1:
    dt = min(step_size, 1 - t_start)
    x_start = x_start + dt * velocity(x_start, t_start)
    t_start = min(t_start + dt, 1)
    states.append((t_start, x_start))
  return x_start, states

2. Classifier-Free Guidance

2.1 CFG

For each step, the model is evaluated twice at the same \(x_t\) and \(t\): once with the prompt (\(v_c\)) and once with the empty-string prompt (\(v_u\)). Following the notebook's convention, these are combined as

\[v_{\text{cfg}} = v_c + w\,(v_c - v_u),\]

so \(w = 0\) is ordinary conditional sampling (checked: cfg_velocity(..., w=0) equals predict_velocity(...) exactly). I used \(w = 7\) and the same five initial noises as Section 1.6.

def cfg_velocity(x, t, condition, w, predict_velocity, null_condition=''):
    vc = predict_velocity(x, t, condition)
    vu = predict_velocity(x, t, null_condition)
    return vc + w * (vc - vu)

Guidance fixes every failure from Section 1.6: all five are clean, well-lit, anatomically correct studio portraits. Each seed keeps the rough layout of its unguided version (seed 182 still has the hand raised to the cheek). The cost is diversity: the guided images share the same centered, front-facing composition, dark or plain backgrounds, and high contrast, so they look much more alike than the unguided set did.

3. Creative Applications

All results in this section use \(h = 0.02\), \(w = 7\), and the empty prompt for the unconditional branch.

3.1 Image-to-image editing (SDEdit)

To edit an image, I push it partway back toward noise and let the guided sampler bring it back onto the manifold of natural images. A smaller \(t_{\text{start}}\) adds more noise, so the model has to invent more.

def edit(image, noise, t_start, condition, predict_velocity, w=7, step_size=0.02):
    noised_image = interpolate(image, noise, t_start)
    guided_v = lambda x, t: cfg_velocity(x, t, condition, w, predict_velocity, null_condition)
    x_1, _ = euler_sample(noised_image, t_start, step_size, guided_v)
    return x_1

Prompt: "a high quality photo". Starting times run from most noise (left) to least.

3.2 Text-guided image editing

Same procedure and starting times, but with a prompt describing the edit instead of the generic photo prompt. Lower starting times give the prompt more control; higher ones preserve more of the input.

Campanile → "a white crayon standing on a lake"

At 0.02–0.06 the prompt wins: a white crayon-like column with a pointed tip rises out of a lake, with the trees reflected around it. At 0.10–0.14 the result is a hybrid, a smooth crayon-shaped shaft with the Campanile's window and proportions. From 0.25 the tower wins and the edit disappears.

Kitten → "a gray furball on a mat"

The low starting times produce a fluffy gray animal sitting on a woven mat. At 0.10–0.14 the furball takes on the kitten's pose and ears, and at 0.25 the kitten is back but with grayer, fluffier fur than the original, which shows the prompt still has a small effect.

Cartoon bear → "a photograph of a bear behind a tree"

At 0.02 the edit is a real brown bear peeking around a tree trunk. At 0.04–0.06 the bear keeps the cartoon's golden color and the tree on the right. At 0.10–0.14 the result is a stylized bear in the cartoon's exact pose. From 0.25 the original cartoon dominates.

3.3 Visual anagrams

At every Euler step, I predict a guided velocity for prompt A on the upright image, and a guided velocity for prompt B on the image rotated 180°, rotate that prediction back, and average the two. The final image has to satisfy both prompts at once, one in each orientation.

\[v = \tfrac12\Big[v_{\text{cfg}}(x_t, t, p_1) + F\big(v_{\text{cfg}}(F(x_t), t, p_2)\big)\Big]\] 
def visual_anagrams(noise, condition_a, condition_b, predict_velocity, w=7, step_size=0.02):
    def anagram_v(x, t):
        v1 = cfg_velocity(x, t, condition_a, w, predict_velocity)
        v2 = rotate180(cfg_velocity(rotate180(x), t, condition_b, w, predict_velocity))
        return (v1 + v2) / 2
    x_final, _ = euler_sample(noise, 0, step_size, anagram_v)
    return x_final

\(F\) is torch.flip(x, (-2, -1)), a true 180° rotation (both spatial axes), and \(F(F(x)) = x\) checks out.

Car ↔ pumpkin (seed 180)

Rotated, the image is clearly a pumpkin with its stem on top. Upright, the same orange mass reads as a rounded car body with dark wheel arches, although the car is the weaker of the two readings.

Natural scenery ↔ girl (seed 181)

This one works in both directions. Upright it is a green valley with trees and a desert mesa in the distance; rotated, the two clumps of trees become the girl's hair, and the valley floor becomes her face.

3.4 Hybrid images

Following Factorized Diffusion, each Euler step combines the low frequencies of one guided prediction with the high frequencies of the other. The low-pass filter is a Gaussian blur with kernel size 265 and \(\sigma = 16\); the high-pass is the prediction minus its low-pass.

\[v = f_{\text{lowpass}}\big(v_{\text{cfg}}(x_t, t, p_1)\big) + f_{\text{highpass}}\big(v_{\text{cfg}}(x_t, t, p_2)\big)\] 
def make_hybrids(noise, condition_a, condition_b, predict_velocity, w=7, step_size=0.02):
    def hybrid_v(x, t):
        v1 = cfg_velocity(x, t, condition_a, w, predict_velocity)
        v2 = cfg_velocity(x, t, condition_b, w, predict_velocity)
        return lowpass(v1) + v2 - lowpass(v2)
    x_final, _ = euler_sample(noise, 0, step_size, hybrid_v)
    return x_final

Up close you see the high-frequency prompt; shrunk to 64×64 (or viewed from far away), only the low-frequency structure remains.

Flowers (near) / guitar (distant)

Up close this is a black-ink bouquet. The guitar comes through in the silhouette: a long thin stem at the top acts as the neck, and the wide dark mass of leaves at the bottom acts as the body.

Tiger (near) / mountain (distant)

Up close, a striped tiger lies on a blue textured ground. The mountain prompt shows up only weakly: at small size, the pale upper half and the dark band below read as a horizon line rather than a peak, so the tiger still dominates. This pair is the less successful of the two.
